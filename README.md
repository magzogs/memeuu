# Memeuu

긴 영상 한 편을 내 컴퓨터의 AI로 세로형 쇼츠 여러 개로 바꾸는 데스크톱 앱입니다. 영상은 컴퓨터 밖으로 나가지 않습니다.

Memeuu turns one long video into several vertical shorts with AI that runs on your own computer.

이 저장소에는 Memeuu 설치 파일과 릴리스 노트만 있습니다. 최신 버전은 [Releases](https://github.com/magzogs/memeuu/releases)에서 내려받으세요.

## 설치

- macOS (Apple silicon): `Memeuu-<버전>-arm64.dmg`
- 음성 인식과 인코딩에 쓰는 도구는 따로 설치합니다: `brew install ffmpeg whisper-cpp`
